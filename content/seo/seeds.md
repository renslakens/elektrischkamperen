# Seeds

Eén seed per kop (`##`), varianten als lijst eronder. `npm run seo:expand` leest dit
bestand met de provider "handmatig" en gebruikt de koppen als seed voor de andere
providers (zoals autocomplete). Dit bestand onderhoud je zelf; er staan geen cijfers in.
